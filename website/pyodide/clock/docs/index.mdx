# Interaktive Uhr

Python steuert die Zeiger einer React-Komponente. Alle Winkel sind in Grad angegeben.

<CodeShowcase lang="md" imports={[`import Clock from '@tdev/pyodide/clock/src/components/Clock';`]}>
<Clock clockId="sbb-uhr" />

```py live_pyo id=e63340b1-3821-4b70-99af-602272a48d8d title=Interaktive_Uhr
from clock import use_clock
from time import sleep
uhr = use_clock("sbb-uhr")

while True:
    uhr.set_seconds(uhr.seconds + 1)
    if uhr.seconds % 360 == 0:
        sleep(0.99)
        uhr.set_minutes(uhr.minutes + 6)
        if uhr.minutes % 360 == 0:
            uhr.set_hours(uhr.hours + 30)
    sleep(0.01)
```
</CodeShowcase>

## Eigenes Zifferblatt

Mit `ticks` wird die Anzahl Striche auf dem Zifferblatt festgelegt, mit `majorTickEvery` jeder wievielte Strich fett gezeichnet wird. Einzelne Zeiger lassen sich mit `hideHours`, `hideMinutes` und `hideSeconds` ausblenden.

`set_pointer(zeiger, tick)` setzt einen Zeiger direkt auf einen Strich des Zifferblatts. Bei 100 Strichen (0 bis 99) zeigt `set_pointer('seconds', 50)` also auf 180°. Mit `within` dreht sich der Zeiger animiert innerhalb der angegebenen Anzahl Sekunden an die neue Position.

<CodeShowcase lang="md" imports={[`import Clock from '@tdev/pyodide/clock/src/components/Clock';`]}>
<Clock clockId="hundert-uhr" ticks={100} majorTickEvery={10} hideHours hideMinutes />

```py live_pyo id=08bbe062-1e53-4790-b329-dd3c5dc03054 title=Hundert_Striche
from clock import use_clock
from time import sleep
uhr = use_clock("hundert-uhr")

for tick in range(101):
    uhr.set_pointer('seconds', tick)
    sleep(0.05)

uhr.set_pointer('seconds', 50, within=1)  # zurück auf 180°, Animation während 1 Sekunde
```

## Aufbau der Erweiterung

Die Uhr verwendet die allgemeine [Erweiterungs-API](../../README.mdx#eigene-erweiterungen-weitergeben). Nachrichtentypen, Worker, Browser-Store und React-Komponente liegen gemeinsam im kopierbaren Ordner.

### Gemeinsamer Nachrichtentyp

```ts title="website/pyodide/clock/protocol.ts"
export type PointerName = 'hours' | 'minutes' | 'seconds';

export interface ClockTime {
    hours: number;
    minutes: number;
    seconds: number;
}

export type ClockUpdate = Partial<ClockTime> & {
    /** pointer positions in ticks of the dial (e.g. 0-99 for a dial with 100 ticks) */
    ticks?: Partial<Record<PointerName, number>>;
};
```

Eine Nachricht kann einzelne Zeiger oder die ganze Uhr ändern. Werte in `ticks` rechnet erst die React-Komponente anhand ihrer Strichanzahl in Winkel um. Worker und Browser-Handler verwenden `ClockUpdate` als Typparameter.

## Komponente

`clockId`
: Verbindet die Komponente mit einem Python-Handle.
`ticks` (Standard: `60`)
: Anzahl Striche auf dem Zifferblatt.
`majorTickEvery` (Standard: `5`)
: Jeder wievielte Strich fett gezeichnet wird.
`hideHours`, `hideMinutes`, `hideSeconds`
: Blenden den jeweiligen Zeiger aus.

## Python-Handle

`use_clock(id)`
: Verbindet den Handle mit der `clockId` der React-Komponente. Jeder Aufruf erzeugt einen eigenen Handle mit lokalen Nullwerten.
`hours`, `minutes`, `seconds`
: Lesen die letzten Werte dieses Handles (Winkel bzw. Strich nach `set_pointer`), nicht den Browser-Store oder andere Handles.
`set_hours(winkel)`, `set_minutes(winkel)`, `set_seconds(winkel)`
: Ändern jeweils nur den zugehörigen Zeiger im Browser.
`set_pointer(zeiger, tick, within=None)`
: Setzt den Zeiger `'hours'`, `'minutes'` oder `'seconds'` auf einen Strich des Zifferblatts. Der Winkel ergibt sich aus `tick * 360 / ticks` der jeweiligen Komponente. Mit `within` (Sekunden) wird die Bewegung animiert, z.B. `set_pointer('seconds', 30, within=0.3)`.
`set_time(stunden, minuten, sekunden)`
: Setzt alle drei Zeiger. Die Argumente sind Winkel in Grad.
`reset()`
: Setzt alle Zeiger auf null.

## Zustand und Lebensdauer

Mehrere Komponenten mit derselben `clockId` teilen den Zustand im Browser-Store. Dieser bleibt nach Ende oder Abbruch eines Skripts erhalten; ein Neustart setzt ihn nicht automatisch zurück. Ein unbekanntes Ziel wird beim ersten Update im `ClockStore` angelegt, auch wenn noch keine React-Komponente dafür angezeigt wird.

Ein neuer Python-Handle beginnt dagegen wieder bei null und verändert die Anzeige erst mit seinem ersten Update. Die Erweiterung bietet keine Rückfragen vom Browser an Python.

Für Hilfsmodule, die Handles oder Factory-Referenzen speichern, gelten die Hinweise zur [Wiederverwendung von Workern](../../README.mdx#zustand-und-lebensdauer).
