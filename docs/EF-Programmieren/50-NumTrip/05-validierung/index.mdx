# Input-Validierung
:::aufgabe[User Input validieren]
<Answer type="state" id="60a2eb84-8f87-4202-a6c7-14cf5189ba84" />

Überprüfen Sie im NumTrip Spiel die Benutzereingaben, so dass auch bei fehlerhaften Eingaben das Programm nicht abstürzt.
:::

:::info[Erneut nachfragen ist nicht nötig]
Im Kapitel [Umgang mit Fehlern](../../07-Try-Except/index.mdx#eingabe-wiederholen) haben Sie gesehen, wie man mit einer `while`-Schleife so lange nachfragt, bis eine gültige Eingabe vorliegt. In NumTrip brauchen Sie das vermutlich nicht: Im letzten Kapitel haben Sie bereits dafür gesorgt, dass immer wieder nach einer nächsten User-Eingabe gefragt wird.

Es reicht also, eine fehlerhafte Eingabe zu **erkennen**, **abzufangen** und die Runde zu **ignorieren** (z.B. mit einer kurzen Meldung). Die nächste Runde fragt automatisch wieder nach.
:::
