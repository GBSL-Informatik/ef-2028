# 🧻 2025, Tag 4: Die Druckerei

## Teil 1

<AdventOfCode title="Tag 4: Die Druckerei" href="https://adventofcode.com/2025/day/4">
Weil die Aufzüge nicht funktionieren, fahren Sie mit der Rolltreppe hinunter in die Druckerei. Hier bereitet man sich eindeutig auf Weihnachten vor: Überall stehen grosse *Papierrollen*, und in der Ecke steht sogar ein riesiger Drucker (für die wirklich grossen Druckaufträge).

Dekorieren wird hier einfach &ndash; die Elfen können ihre Dekoration selbst drucken. Was Sie wirklich brauchen, ist ein Weg, um tiefer in die Nordpol-Basis vorzudringen, solange die Aufzüge ausser Betrieb sind.

«Vielleicht können wir da helfen», meint einer der Elfen, als Sie um Hilfe bitten. «Wir sind ziemlich sicher, dass hinter der hinteren Wand die Cafeteria liegt. Wenn wir die Wand durchbrechen könnten, kämen Sie weiter. Schade nur, dass alle unsere Gabelstapler damit beschäftigt sind, die grossen Papierrollen herumzufahren.»

Wenn Sie die Arbeit der Gabelstapler optimieren, hätten diese vielleicht Zeit, die Wand zu durchbrechen.

Die Papierrollen (`@`) stehen auf einem grossen Raster. Die Elfen haben sogar einen praktischen Plan (Ihr *Rätsel-Input*), auf dem eingezeichnet ist, wo alles steht. Zum Beispiel:

```
..@@.@@@@.
@@@.@.@.@@
@@@@@.@.@@
@.@@@@..@.
@@.@@@@.@@
.@@@@@@@.@
.@.@.@.@@@
@.@@@.@@@@
.@@@@@@@@.
@.@.@@@.@.
```

Ein Gabelstapler kommt nur an eine Papierrolle heran, wenn auf den *acht benachbarten Feldern* (waagrecht, senkrecht und diagonal) *weniger als vier* Papierrollen stehen. Wenn Sie herausfinden, welche Rollen zugänglich sind, verbringen die Gabelstapler weniger Zeit mit Suchen und mehr Zeit damit, die Wand zur Cafeteria einzureissen.

In diesem Beispiel sind *`13`* Papierrollen für einen Gabelstapler zugänglich (mit `x` markiert):

```
..xx.xx@x.
x@@.@.@.@@
@@@@@.x.@@
@.@@@@..@.
x@.@@@@.@x
.@@@@@@@.@
.@.@.@.@@@
x.@@@.@@@@
.@@@@@@@@.
x.x.@@@.x.
```

*Werten Sie Ihren vollständigen Plan aus. Wie viele Papierrollen sind für einen Gabelstapler zugänglich?*
</AdventOfCode>

:::details[Hinweis 1: Den Plan als zweidimensionale Liste speichern]{.orange}
Mit `splitlines()` erhalten Sie eine Liste von Zeilen. Mit `list(...)` wird aus jeder Zeile eine Liste von einzelnen Zeichen. Mit `plan[zeile][spalte]` kann so jedes Feld abgefragt werden:

```py live_py slim
with open("./demo.txt", "w") as f:
    f.write('..@@.@@@@.\n@@@.@.@.@@\n@@@@@.@.@@\n@.@@@@..@.\n@@.@@@@.@@\n.@@@@@@@.@\n.@.@.@.@@@\n@.@@@.@@@@\n.@@@@@@@@.\n@.@.@@@.@.')
### PRE
with open("./demo.txt") as file:
    raw = file.read()
plan = [list(zeile) for zeile in raw.splitlines()]
print(plan[0])
print(plan[0][2])
```
:::

:::details[Hinweis 2: Nachbarn zählen]{.orange}
Die acht Nachbarn eines Feldes liegen um höchstens eine Zeile und eine Spalte verschoben. Mit zwei Schleifen über die Verschiebungen `-1`, `0` und `1` können Sie alle Nachbarn besuchen &ndash; die Verschiebung `(0, 0)` ist das Feld selbst und zählt nicht.

Achtung am Rand: Felder ausserhalb des Plans enthalten keine Papierrolle. Prüfen Sie also, ob die Nachbarposition überhaupt im Plan liegt, bevor Sie darauf zugreifen. (Ein negativer Index wie `plan[-1]` ist in Python erlaubt und liefert die *letzte* Zeile &ndash; das wäre hier falsch!)

Verwenden Sie zum Rechnen Ihre eigene Liste und nicht `board[...].get(...)` &ndash; das Gitter verbindet die gegenüberliegenden Ränder.
:::

Jetzt brauchen die Elfen nur noch Hilfe, um an möglichst viel Papier heranzukommen.

Sobald ein Gabelstapler an eine Papierrolle herankommt, kann diese *entfernt* werden. Ist eine Rolle entfernt, kommen die Gabelstapler vielleicht an weitere Rollen heran, die dann ebenfalls entfernt werden können. Wie viele Papierrollen können die Elfen insgesamt entfernen, wenn sie diesen Vorgang immer wiederholen?
