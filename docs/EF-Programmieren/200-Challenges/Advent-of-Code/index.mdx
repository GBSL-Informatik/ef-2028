# 🎄 Advent of Code

<AdventOfCode title="Advent of Code">
[Advent of Code](https://adventofcode.com) ist ein Adventskalender mit *Programmier-Rätseln*. Jeden Tag ab dem *1. Dezember* wird um 06:00 Uhr (Schweizer Zeit) ein neues Rätsel freigeschaltet. Rund um die Welt knobeln jedes Jahr Hunderttausende Menschen mit &ndash; von Programmier-Neulingen bis zu Profis.

Für jedes gelöste Rätsel gibt es einen Stern <Star />. Seit 2025 gibt es *12 Tage* mit Rätseln, also bis zum 12. Dezember.
</AdventOfCode>

## So funktioniert's

- **Eine Geschichte:** Jedes Jahr gibt es eine weihnachtliche Rahmengeschichte rund um die Elfen am Nordpol. Jedes Rätsel ist ein Kapitel davon.
- **Zwei Teile pro Tag:** Jedes Rätsel besteht aus zwei Teilen. Der zweite Teil wird erst sichtbar, wenn der erste gelöst ist &ndash; und er ist meistens eine knifflige Erweiterung des ersten Teils.
- **Persönlicher Input:** Wer eingeloggt ist, erhält zu jedem Rätsel einen eigenen *Rätsel-Input* (meist eine lange Textdatei). Das Programm verarbeitet diesen Input und berechnet eine Antwort &ndash; eine Zahl oder ein kurzer Text.
- **Antwort einreichen:** Die Antwort wird auf der Webseite eingetragen. Ist sie falsch, gibt es manchmal einen Hinweis (z.B. «zu hoch»), und man muss kurz warten, bis man es nochmals versuchen kann.
- **Beispiele nutzen:** Jedes Rätsel enthält ein kleines Beispiel mit bekannter Lösung. Testen Sie Ihr Programm immer *zuerst* mit dem Beispiel, bevor Sie den richtigen Input verwenden.

:::tip[Anmelden]
Um Ihren persönlichen Input zu erhalten und Antworten einzureichen, müssen Sie sich auf [adventofcode.com](https://adventofcode.com/auth/login) anmelden, z.B. mit einem GitHub- oder Google-Konto. Die Rätseltexte sind auch ohne Login lesbar.
:::

:::warning[Fair bleiben]
Der Reiz von Advent of Code liegt darin, selbst auf die Lösung zu kommen. Lassen Sie die Rätsel also nicht von einer KI lösen und teilen Sie Ihren persönlichen Input nicht öffentlich.
:::
